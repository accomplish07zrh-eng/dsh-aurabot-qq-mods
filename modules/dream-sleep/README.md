# 做梦睡觉

让她像真人一样睡觉、做梦。

不是「定时发一句晚安」，而是真的按睡眠周期走：一晚上分几段快速眼动期，每段做一场梦；梦只产出碎片，不是作文；醒来会遗忘，只记得一点点；梦的内容会被她白天做过的事影响；梦的余韵会渗进她的情绪。

## 做什么

**睡觉**

- 按睡眠周期睡：一晚 1-6 段梦（默认 4），每段单独做一场梦，段与段之间隔一段时间
- 入睡时间可以固定、可以随机、可以完全自由
- 入睡快慢随机：有时候秒睡，有时候翻来覆去很久
- **会失眠**：有概率这一夜躺下但睡不着，或者睡得很浅
- 醒来时间随机：可能在窗口里挑，也可能早醒、赖床
- 睡眠深度随机：浅睡（梦少、记得清）/ 正常 / 深睡（梦多、醒了大半忘光）

**做梦**

- 每段梦只写 5-9 行碎片，不写成文章
- 允许自相矛盾、物理不可能、突然跳场景、张冠李戴
- 必须有身体感（躺着、被子、冷热、麻、想翻身）
- 白天做过的事会变形着混进来：B站回复、发的弹幕、抖音刷到什么、写的日记、群聊内容、聊天记录
- 以前梦到过的画面（母题）可能再次出现

**醒来**

- 只记得一小部分（会按比例遗忘）
- 写四到五段：还记得的 / 身体 / 想跟你说 / 梦里出现过 / 分不清是梦还是真的
- 醒来的身体感觉会跟睡眠质量对应（失眠夜写「头沉、眼睛疼、身上发虚」）
- 醒来会讲梦，可以拆成几条发，可以配语音和表情

**跟心情联动**

- 睡前心情影响梦的调子（心情好 → 甜梦；心情差 → 被追、被骂）
- 睡前心情起伏大 → 梦更乱
- 心情差 → 更难入睡、更容易失眠
- 梦到噩梦 → 醒来心情掉；梦到好梦 → 醒来心情涨
- 没睡饱 → 起床气；睡太久 → 懒洋洋

**梦记**

- 一晚一个 Markdown 文件，存在 `dreamDir`
- 可以额外保存原始碎片（各段 REM 的幸存碎片 + 整合后的梦记）
- 梦会写进记忆库（如果装了 memory 或 companion 模块）

## 怎么用

装好后在面板里会出现「做梦睡觉」这一页，可以直接改设置。或者在 QQ 里发：

| 命令 | 作用 |
|---|---|
| `/睡觉` | 现在就去睡（会做梦，醒来讲给你听） |
| `/做梦` | 立刻做一段梦（不占整夜） |
| `/起床` | 现在醒来（把这一夜的梦收一收） |
| `/讲梦` | 把这一夜的梦现在讲给你听 |
| `/看梦` | 把梦记原文贴出来（不走模型） |

## 设置项

### 作息

| 设置 | 默认 | 说明 |
|---|---|---|
| 睡觉开关 | 开 | 关掉就不主动睡；命令还能用 |
| 作息模式 | 在设定时间范围内 | `在设定时间范围内` / `完全自由` / `跟着习惯` |
| 入睡时间 | 01:30-03:30 | 作息模式是「范围内」时用的窗口 |
| 醒来时间 | 07:30-08:40 | 醒来窗口 |
| 一晚几段梦 | 4 | 1-6 |
| 入睡快慢 | 随机 | 随机 / 总是秒睡 / 总是 5-20 分钟 / 总是很难睡着 |
| 失眠概率 | 12% | 0-60，心情差会加倍 |
| 桌宠躺下睡 | 开 | 装了桌宠模块时，睡着播睡觉动画 |

### 梦的内容

| 设置 | 默认 | 说明 |
|---|---|---|
| 梦记目录 | 空（用模块数据目录） | 一个晚上一个文件 |
| 拿当天聊天当素材 | 开 | 用聊天记录当梦的素材 |
| 拿「今天做过的事」当素材 | 开 | B站/抖音/日记/空间/自己做过的事 |
| 梦的碎片数 | 7 | 3-12 |
| 身体感强度 | 正常 | 不要 / 正常（至少 2 行）/ 强（至少 4 行） |
| 梦的基调 | 跟着心情走 | auto / 日常琐碎 / 离奇荒诞 / 温柔甜 / 压抑 |
| 梦里出现你 | 自然出现 | auto / 不出现 / 经常出现 |
| 梦的引子 | 15 个内置 | 一行一个，只给「一个东西」不给情节 |

### 醒来

| 设置 | 默认 | 说明 |
|---|---|---|
| 醒来第一件事 | 马上讲梦 | 马上讲 / 先躺一会儿 / 先写日记 |
| 保留梦的原始碎片 | 开 | 存到 `dreamDir/raw/<night>.txt` |
| 允许「分不清是梦还是真的」 | 开 | 多写一段，存记忆时标成「分不清」 |

### 梦的结构（高级）

| 设置 | 默认 | 说明 |
|---|---|---|
| 梦里有时间轴 | 开 | 每段梦最后写「这段里过了多久」 |
| 梦之间有连续性 | 开 | 后一段梦会带上前一段的残留 |
| 允许梦里跨时代 | 关 | 梦到很久以前 |
| 清醒梦 | 少见 | 常见 / 少见 / 从不 |
| 允许突然出现无关的东西 | 开 | 梦会莫名其妙跳进来一个东西 |
| 梦的余韵渗进人格 | 开 | 醒来后一段时间，说话会带梦的影子 |

## 会访问哪些网址

**不联网。** 这个模块不请求任何外部网址。

梦的素材全部来自本机已有的数据：

- 插件自己的 `chatlog/` 聊天记录
- 插件的 `bili.json`、`douyin.json`、`diary.json`、`qzone-social.json`（如果装了对应模块）
- 模块自己的 `modules-data/<id>/` 数据目录
- 你设置的 `dreamDir` 目录

## 需要什么

- Aurabot 插件 1.2.0 或更高
- 能用的模型（做梦、整合、讲梦都要调模型）
- 可选：`memory` 或 `companion` 模块（梦会写进记忆库）
- 可选：`mood` 模块（心情联动）
- 可选：`pet` 模块（桌宠躺下动画）

## 数据在哪

- 梦记：你设置的 `dreamDir`（默认是模块数据目录下的 `dreams/`）
- 原始碎片：`dreamDir/raw/<日期>.txt`
- 睡眠状态：模块数据目录的 `sleep-state.json`
- 梦的母题：模块数据目录的 `motifs.json`

删掉模块文件夹，这些数据不会自动删；想彻底清掉要手动删 `dreamDir` 和模块数据目录。
