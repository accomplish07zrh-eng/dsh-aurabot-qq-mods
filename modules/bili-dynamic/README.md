# B站发动态

她会自己发 B 站动态（文案她自己写），主人也能让她马上发一条。

## 做什么

- 定时（每 15 分钟看一次）判断该不该发：只在设定时段内、每天条数没满、两条之间至少隔 3 小时
- 文案由她自己写：带人格、口语、15～80 字，不会写成「文案」
- 不想发的时候会跳过（模型输出「[不发]」就不发）
- 主人可以直接说要发，或者发命令 `/发动态 今天好累` 指定内容
- 发出去的动态记成她自己的经历，之后聊天能想起来

## 怎么用

先在 Aurabot 面板「B站」页登录 B 站（SESSDATA + bili_jct）。模块读的就是这份登录态，不额外存账号。

设置里能调：每天最多几条、从几点到几点可以发、要不要自己发。

## 会访问什么

- B 站接口：`api.vc.bilibili.com`（发动态，POST）
- `api.bilibili.com`（只在插件内部校验登录时用到，本模块不直接调）

只读插件配置里的 B 站登录 Cookie（`plugin-config`），不发往别处。
不刷量、不批量发，一天最多几条，主人可随时关掉。
