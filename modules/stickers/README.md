# 表情包

她会发表情，也会**偷**表情。

这是插件内置「表情包」模块的**独立增强版**，装上会替换内置的（`replacesBuiltin: true`）。

## 做什么

**收表情**

聊天里别人发的表情、贴纸，她会自动存进自己的表情库（可关）。

**发表情**

回复时按情绪自动配一张：开心、委屈、害羞、生气、早晚安……也能直接在回复里写 `<sticker:名字>` 指定。

**整理表情库**

- 给表情改名、打标签、写使用场合
- 删掉不要的
- 黑名单 / 白名单规则（按名字、标签、情绪、分组、素材包、id、文件名筛）
- 分页 + 搜索（库大了不卡）
- 批量启用 / 停用
- 规则预览（写完就能看到这条规则命中几张）

## 怎么用

### 工具

| 工具 | 作用 |
|---|---|
| `qq_send_sticker` | 在当前聊天里发一张表情（按名字/情绪/场合模糊匹配） |
| `qq_sticker_library` | 看看表情库里有什么（非主人只能看到数量） |

### 面板

面板「表情包」页：

- 表情库列表（分页、搜索、按可用/不可用筛）
- 每张的启用开关
- 黑名单 / 白名单规则编辑
- 规则预览（实时看命中几张）
- 批量操作

## 设置项

| 设置 | 默认 | 说明 |
|---|---|---|
| 表情包开关 | 开 | 关掉后不发也不收 |
| 自动收表情 | 开 | 别人发表情时存进库 |
| 自动配表情 | 开 | 回复时按情绪自动配 |
| 配表情概率 | 0.35 | 每次回复有多大概率配 |
| 尺寸门槛 | 520 | 超过这个边长不收（QQ 表情要接近方形） |
| 黑名单规则 | 空 | 一行一条，命中的不发表情 |
| 白名单规则 | 空 | 一行一条，只有命中的才能发（开了白名单就只认白名单） |
| 库上限 | 500 | 超过按淘汰策略删 |

### 规则语法

规则前缀（不写前缀就是按名字模糊匹配）：

| 前缀 | 作用 | 例子 |
|---|---|---|
| `tag:` | 按标签 | `tag:委屈` |
| `name:` | 按名字 | `name:猫猫` |
| `emotion:` | 按情绪 | `emotion:开心` |
| `group:` | 按分组 | `group:日常` |
| `pack:` | 按素材包 | `pack:default` |
| `id:` | 按 md5 | `id:abc123...` |
| `file:` | 按文件名 | `file:cat.gif` |

## 会访问哪些网址

**只在「偷表情」时下载图片**，而且只下载 QQ 消息里已经出现的图片地址（`multimedia.nt.qq.com.cn`、`gchat.qpic.cn` 等腾讯自己的域名）。

**不访问任何第三方网站。** 没有素材包下载、没有统计上报。

## 隐私

- 表情存在本机 `plugins-data/aurabot/stickers/`
- 元数据（名字、标签、用途）存在 `plugins-data/aurabot/stickers.json`
- 不会把表情或元数据发到任何外部服务器
- 偷表情只发生在**当前聊天里别人发的图**，不会去别的地方抓

## 需要什么

- Aurabot 插件 1.2.0 或更高
- 可选：`llm` 服务（用来看图打标签，没有就只按尺寸和类型判断）

## 数据在哪

- 表情文件：`plugins-data/aurabot/stickers/<md5>.<ext>`
- 元数据：`plugins-data/aurabot/stickers.json`

## 与内置模块的关系

本模块 `replacesBuiltin: true`，装上后替换内置「表情包」。想用回内置的：面板「已安装」页那一行切「用内置的」，或删掉 `modules/stickers/`。

## 相比内置版新增

- **黑名单 / 白名单规则**：7 种前缀（tag/name/emotion/group/pack/id/file），支持模糊匹配
- **分页 + 搜索**：`/sticker/page` 接口，库大了不卡
- **批量启用 / 停用**：`/sticker/enable`，支持一次传多个 md5
- **规则预览**：`/sticker/rule-preview`，写完规则实时看命中几张
- **可用性状态**：每张表情带 `usable` / `why`，面板上直接看为什么发不出去
- **非主人限制**：表情库的名单只给主人看，别人只能看到数量

## 第三方

内置「表情包」模块的原始实现来自 Aurabot 插件（MIT）。本模块是它的独立增强版，把插件内部依赖（`src/features/stickers.js`、`src/core/`、`src/chat/inbound.js` 的图片工具）内联到了 `lib/`。
