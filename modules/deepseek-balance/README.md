# DeepSeek 余额

给大肥鱼（Aurabot）加一个查 DeepSeek 账户余额的本事：有人在聊天里发「余额」，她回一句「DeepSeek 余额：¥12.34」。

## 它会做什么

收到触发词后，用你配置的 DeepSeek API Key 调一次官方余额接口，把结果回在那个聊天里：

```
DeepSeek 余额：¥12.34 （赠送 2.00 / 充值 10.34）
```

余额不足（`is_available` 为 `false`）时会换成「余额不足，API 调用会被拒绝：…」。

## 怎么用

1. 装好 Aurabot 插件（v1.2.0 及以上），确认 QQ 网关正常
2. 把 `deepseek-balance` 整个文件夹放进 Aurabot 数据目录的 `modules/` 里
   （默认是 `~/.dsh/plugins-data/aurabot/modules/`），几秒内自动加载
3. 打开面板「已安装」页，找到「DeepSeek 余额」，填上 API Key
4. **打开「模块开关」**（默认是关的），保存
5. 在 QQ 里发「余额」

API Key 在 [platform.deepseek.com](https://platform.deepseek.com/) 的「API keys」页创建，以 `sk-` 开头。

## 设置项

| 设置 | 默认 | 说明 |
|---|---|---|
| 模块开关 | **关** | 装好后不会自己动。要打开才会响应触发词；关掉后完全不响应，也不发任何请求 |
| 触发词 | `余额` | 要她回应的话。可以写多个，用逗号（中英文都行）、顿号或空格分开，例如 `余额, 剩多少` |
| DeepSeek API Key | 空 | 必填。面板里是密码框，不回显；日志里自动打码 |
| 群友也能查 | 关 | 打开后所有人都能查；关着时只有主人能查，别人发触发词会收到「这个只有主人能查哦～」 |
| 接口地址 | `https://api.deepseek.com/v1` | 一般不用改。走中转或自建代理时填你自己的地址 |

设置改完保存就生效，不用重载模块。

### 模块开关

**默认关闭**：刚装好、还没配 Key 时，模块对任何消息都不接管，不会打扰她正常聊天。

关着的时候模块仍在运行（面板「已安装」页显示正常），但对消息**完全不接管**：不匹配触发词、不回复、不联网。发「余额」时她按平时的方式回答，就像没装这个模块。

打开时缓存会被清空，第一次查询拿的一定是新数据。

## 谁能用

- **主人**：任何时候都能查
- **别人**：要把「群友也能查」打开

余额是账户级信息，群友看到的就是你整个账户的余额。多人群里建议保持关闭。

## 它会访问哪些网址

| 地址 | 什么时候 |
|---|---|
| `https://api.deepseek.com/v1/user/balance` | 每次收到触发词时（结果缓存 30 秒） |
| `https://api.deepseek.com/user/balance` | 只有上一条返回 `404`/`405` 时，自动退回根路径再试一次（实测两个路径都能通，这是保险） |
| 你把「接口地址」改成别的时，访问 `<那个地址>/user/balance` | 同上 |

「模块开关」关着时，一次请求都不发。

除此之外不发任何请求，也不读你本机的文件、Cookie 或 QQ 消息以外的内容。

## 隐私

- API Key 存在 Aurabot 自己的配置里（本机），只放在请求头 `Authorization: Bearer <key>` 里发给上面列出的地址
- 日志里不会出现 Key（插件会自动打码）
- 请求里只有这个 Key，不带 QQ 号、昵称、聊天内容

## 出错时会回什么

| 情况 | 回复 |
|---|---|
| 模块开关关着 | 什么都不回，消息交给她正常处理 |
| 没填 Key | 提示去面板填写 |
| `401` | API Key 无效或已过期，去重新生成 |
| `403` | 这个 Key 没有查询余额的权限 |
| 其它 HTTP 错误 | `查询失败（HTTP 状态码）：服务端返回的原因` |
| 8 秒没响应 | 查询超时 |
| 连不上 | 连不上这个地址 + 具体错误 |

失败原因也会写进面板「日志」页，按模块 id 分类。
