# 刷抖音

用专用浏览器刷抖音：看推荐、点赞、评论，把好玩的视频分享给主人，也能看别人发来的抖音链接。

在面板「抖音」页登录并打开。开关关闭时也可以扫码登录；登录动作进行中及最近一次登录动作后的五分钟内，定时任务不会关闭登录浏览器。各项权限在面板「权限」页，默认仅主人。会启动本机 Chromium 内核浏览器并访问 `douyin.com`。

原是 Aurabot 内置模块，1.2.0 起搬到社区模块库。老用户升级时，在用的会自动装回来，配置和登录状态不变。

## 怎么工作

专用浏览器（独立的登录资料目录，Edge / Chrome / Chromium，经 CDP 控制，窗口放在屏幕外）。数据都走抖音网页自己的接口（在页面里 fetch，签名由页面脚本自动加，不自己算 a_bogus），不读屏：标题、分类、抖音给的内容摘要和分段、热评。一个个点开看（真的播放、停留），再按人格决定点赞 / 评论 / 分享给主人（抖音私信分享视频卡片、QQ 私聊发她的话 + 链接，或两边都发）/ 记住什么；特别想让主人看的，会在评论里真·@主人（用抖音自己的 @ 选人，按 sec_uid 认人，认不出就不发）。点赞 / 评论在弹层播放器里按视频 id 找按钮，点完等接口回应才算成功；页面看不见（锁屏）时用页面内事件。扫一次码登录（面板里显示登录弹窗截图）。打开面板不启动浏览器；验证码每次现查，遇到就当天停手。每天上限、两次操作间隔、新号前几天减半；4 项权限默认仅主人；总开关默认关。主人在抖音私信她，她会回（只认核对过的主人）；评论被抖音要求身份验证拦下时能认出来。

## Linux

需要 Chrome / Chromium / Edge，而且不能用无头模式（抖音会拦）。没有桌面的服务器上用 Xvfb 之类的虚拟显示跑，比如 `xvfb-run` 启动 DSH，或在容器里起一个 Xvfb 再设 `DISPLAY`。浏览器路径可以在面板里填，也可以设环境变量 `CHROME_PATH`。
