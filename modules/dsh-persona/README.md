# DSH 人设与风格 🧩

把一张人格卡连同「思考风格 / 回复风格」注入 **DSH 的所有会话**（DeepSeek Harness 侧），
让你在 dsh 里干活、聊天时都按选定的人格说话——效果类似 `dsh-cosplay`，但人格直接复用
Aurabot 面板「人格」页里已经写好的那些卡，不用再建一套角色库。

**不改变大肥鱼 QQ 聊天用的人格**：QQ 管线照常走「人格」页选中的那张卡，两边互不干扰。

## 做什么

- **注入 DSH 的人格**：默认「跟随当前人格」（面板人格页「正在用」的那张），也可以下拉换成任意一张；
- **思考风格**：
  - `中立思考`（默认）：模型思考过程保持专业分析，只在最终回复里扮演角色——保 Agent 干活能力，推荐；
  - `角色化思考`：思考过程也保持角色口吻，沉浸感更强（概率性触发，可能影响 Agent 任务能力，谨慎开启）；
- **回复风格**：
  - `完整人设`（默认）：整张人格全文注入；
  - `精简人设`：只注入「开场」+「怎么说话 / 语气 / 打字习惯」这类短节（人设按【标题】分节才生效；
    没分节的卡自动退回全文），干活时干扰更小；
- **确认生效**：所有改动先暂存，点「确认生效」才应用，下一轮对话起生效；
- **默认不注入**：装好即静默；关掉「启用注入」开关即撤销，已注入的内容下一轮对话起消失、无残留。

## 怎么用

1. 面板「扩展」页安装本模块后，左侧「人设」分组多出一页 **「DSH 人设」**；
2. 打开「启用注入」开关 → 选人格 → 选思考/回复风格 → 点 **「确认生效」**；
3. 新开（或继续）一个 DSH 会话说话，下一轮起就是那个人设；
4. 想恢复默认：关掉「启用注入」→「确认生效」即可，注入立即撤销。

## 会访问什么

- 读 Aurabot 的人格卡（`api.core.personas`，本机数据目录，不上传）；
- 经插件内部接口（`api.dsh.systemPrompt`）往 DSH 系统提示词追加一段人格；
- 不联网、不读写其他文件、不启动程序。

## 与 dsh-cosplay 的关系

功能定位相似，互不冲突：注入段名、变量名都错开了，同时装不会互相覆盖——
但两份人格会**叠加**进系统提示词，建议只开一个。
