# 人格实验室

让 AuraBot 观察群友的说话方式，并允许她在主人会话里给自己的人格追加一条「自我调整」；授权后也可以重写整份人格。自带备份、撤销和可选的定期自我反思。

> 只影响 AuraBot 的人格文件，不修改 AuraBot 插件本体，也不修改 `ownerQQ`。主人是谁始终由 AuraBot 配置决定。

## 功能

- **群友口癖**：只记录群聊文字，按群友归纳平均句长、问号/感叹号/省略号/波浪号习惯、常用表情、常用口头禅、拖音/叠字和句尾语气词；不会把“风扇、理由”这类内容词当成口癖。
- **群聊参考**：可选把最近几位群友的说话习惯作为语气参考注入群聊上下文；默认关闭，只在她主动查时使用。
- **自主改人格**：
  - 追加模式：只在人格末尾加 `【自我调整】`，不改核心规则。
  - 重写模式：允许重写整份人格；不会修改主人身份。
- **定期自我反思**：按间隔回顾最近和主人的相处，只有真的觉得有新的自我认识时才追加一条，不会为了改而改。
- **备份看板**：每次修改前自动备份；面板可恢复、撤销最近一次、删除单份备份。
- **清空样本**：面板一键清空「学习群友说话方式」保存的群友说话样本，不影响已写入人格的内容和人格备份；样本写入有 5 秒防抖，群多时不频繁写盘。
- **撤销工具**：`persona_undo` 恢复最近一份备份。

## 默认值

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| 学习群友说话方式 | 关 | 只记录群聊文字；默认关闭，需要手动开 |
| 群聊时参考群友的说话习惯 | 关 | 开启后可能自然借鉴语气 |
| 允许她自主改人格 | 关 | 总开关 |
| 修改范围 | 追加模式 | 追加 / 重写 |
| 每天最多改几次 | 2 | 防止人格漂移 |
| 两次修改至少隔几小时 | 6 | 0 = 不限制 |
| 定期自我反思 | 关 | 需要先开总开关 |
| 反思间隔 | 6 小时 | 最快 1 小时 |
| 每天最多反思几次 | 2 | 0 = 不反思 |

## 工具

- `group_style_profile`：查看群友的说话习惯（主人可见）。
- `persona_edit`：追加一条自我调整（仅主人会话）。
- `persona_rewrite`：重写整份人格（仅重写模式、仅主人会话）。
- `persona_undo`：恢复最近一份备份。

## 安全与隐私

- 只有主人会话能改人格；群聊和其他人的会话会被拒绝。
- 修改前自动备份，备份保留最近 12 份。
- 默认关闭自主修改、定期反思和群友学习。
- 群友样本只存在本机 `modules-data/persona-lab/`，不上传；不会保存图片、语音或文件。
- 不读取也不修改 `ownerQQ`；主人身份始终由 AuraBot 配置决定。
- 重写模式不校验“主人原句”，因为主人身份不在人格文件里；如不希望她改核心，请保持追加模式。

## 试运行

AuraBot 打开「试运行」时：

- 不会写入人格
- 不会创建备份
- 不会写入口癖样本
- 工具会返回“试运行：会做什么”，不会真的执行

面板里的手动恢复/删除备份属于管理员操作，不受试运行影响。

## 会访问哪些网址

不访问任何外部网址。模型调用走 AuraBot 现有配置；群友样本和备份只写本机数据目录。

## 能力声明

`module.json` 声明：

- `plugin-config`：读写本模块设置
- `filesystem`：读写本机样本与备份
- `plugin-internals`：读取人格、调用主人会话判断和面板路由

不使用网络、进程启动或动态代码执行。

## 安装

把本目录放到：

```text
plugins-data/aurabot/modules/persona-lab
```

重启或等 AuraBot 自动加载，在面板「已安装」里看到「人格实验室」。
