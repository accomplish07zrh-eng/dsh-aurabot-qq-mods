# 房间（room3d）

一个能走能坐的 3D 小屋。小小柒在屋里走来走去、干活、吃饭、发呆，点她会回应；家具、隔断、灯光、镜头都由你摆。

- 三个页面：**房间**（室内）、**世界**（海边小屋外景）、**房间面板**（在 Aurabot 面板里用 iframe 打开）
- 角色动作是一堆 webm 视频贴图，跟着模块一起发，不联网也能跑
- 房间状态（谁在哪、摆了什么、镜头在哪）存在 `modules-data/room3d/`，模块目录永远是静的
- 对话框里问到房间/窗外时，会顺手把当前画面描述塞给模型，她答得上「屋里现在什么样」
- 也会注册 `room3d` 工具，让她自己动手改房间

## 玩法

| 操作 | 效果 |
| --- | --- |
| 按住拖动 / 滚轮 | 旋转、缩放镜头 |
| 点角色 | 打招呼，播一段回应动作 |
| 底部按钮 | 摆家具、加隔断、放猫、换装 |
| 右侧输入 | 让她做事，比如「去窗边」「坐下来」 |

## 安装

Aurabot 插件 **1.2.0 及以上**，在面板「模块市场」安装后启用。装好后面板顶部会出现「房间」，也可以直接开页面。

包里只带小小柒一个角色：老爹、麻麻、老姐、二姐的素材和代码都不在发布内容里。**场景默认不摆家具**（发出去的是空屋，`/api/room/furniture` 返回空的 `items`），但**家具库照旧完整**——81 种预设分 9 类（可爱、客厅、卧室、厨房、卫生间、餐厅、门窗、装饰、其他），拖出来就能摆，摆好可以存成布局。

## 访问地址

模块的页面挂在 Aurabot 自己的端口上：

- 房间：`http://<NAS 内网 IP>:<Aurabot 端口>/aurabot/api/ext/room3d/page`
- 世界：`http://<NAS 内网 IP>:<Aurabot 端口>/aurabot/api/ext/room3d/world`

如果想当成一个独立小站，手机在局域网里直接点开、不用先开面板，就再单独挂一个入口（把 `/` 反代到 `/page`、`/world3d` 反代到 `/world` 即可，模块这边不用改）。作者这台机器上是这样挂的，端口 **6191**：

- 房间：**http://192.168.1.26:6191/**
- 世界：**http://192.168.1.26:6191/world3d**

同一个 Wi-Fi 下的手机、平板直接输这个地址就能看，不需要登录面板。这个入口是 Aurabot 之外单独起的，端口和 IP 按自己的机器换。

## 权限

- `filesystem`：读模块自带的页面和 webm，读写 `modules-data/room3d/` 里的房间状态、截图
- `plugin-internals`：用 `api.core.http` 发响应、`api.core.hub` 广播房间事件给 Aurabot 自己的模块
- `network`：页面里的 `fetch` 只请求本模块的同源接口（`/api/room/*`），不访问外网。页面是 `.html`，仓库的能力扫描会把它算成 `network`，所以显式声明

不上传任何数据，不写用户文件，不下载代码。

## 素材

发布包里的动作是日常那批（待机、走路、点击回应、工作状态、吃饭、碎碎念、几个整活），一共 43 个 webm，压缩后整个模块约 17MB（仓库单模块上限 20MB，全量 106 个动作是 54MB，超了）。

想加动作：把 `<动作名>.webm` 放进模块的 `assets/` 目录，重启模块即可，动作清单是扫目录得到的，缺的不会报错、只是不显示。

## 测试

```sh
node --test "modules/room3d/test/*.test.mjs"
```

覆盖三块：

- 发布内容：`module.json` 和入口的 `id`/`version`/`api` 对得上，页面在 `assets/` 下，没有管理密码、没有旧出处字样
- 场景：只有小小柒一个角色，图例和名牌不再列其他人，家具默认是空的
- 路由：`/page` `/world` 能返回页面，`/api/room/state` 默认只有小小柒，`/api/room/anims` 只列 `.webm` 且滤掉待机/走路/老爹

## 来源与许可

`assets/room.html`、`assets/world.html`、`index.js`、`panel.js` 都是 **zcx1021** 写的，源自作者自己早前那版 3D 房间原型，改成 Aurabot 的模块路由后重写了取数接口和状态存储，页面沿用同一作者的代码。包内没有第三方代码，MIT 许可（见 `LICENSE`）。

3D 引擎用的是随包分发的 three.js（`vendor/`，MIT）。
