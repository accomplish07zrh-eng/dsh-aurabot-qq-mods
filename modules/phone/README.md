# 手机逛逛（phone）

通过 ADB 逛 Android 手机：主人用一句话「教」一个流程（打开应用、点哪个按钮、刷多久），
之后大肥鱼可以自己看着屏幕完成签到、浏览、点赞等任务；没有现成流程时也能自由推理一步步操作。

## 做什么

- **流程库**：`/phone` 命令或面板增删改流程（触发词、目标描述、目标包名、cron 定时、开关）。
- **工作区回合**：占锁 → 截取界面节点（uiautomator dump）→ 让模型回 JSON 动作 → 安全门判定 → 执行（tap/输入/滑动/返回/启动应用）→ 循环到任务完成或步数耗尽；**回合收尾自动强停本轮到过的应用进程释放内存**（「逛完关闭应用」默认开，桌面不受影响）。
- **单段记忆**：每个流程跑完自动总结 ≤300 字可复用经验（有效路径、坑位、重试办法），下次运行优先复用；临时流程跑满 10 次会提示固化为正式流程。
- **安全门**：包名白名单、每分钟限速、写操作（发布/发送/评论/回复/点赞/关注/删除/确认等）默认需主人批准、试运行模式。
- **AI 工具**：`phone_run_flows`（列流程）、`phone_run_flow`（跑流程）、`phone_act`（自由推理一句话任务）、`phone_auto_browse`（主动逛一轮）。忙时自动排队，超过 120 秒会先回「已在后台排队」。决策器每步思考默认在工作区开一条「手机逛逛 · 操作决策」独立会话窗（同碎碎念/行为大脑机制，实时可见）；面板选了「决策模型」或截图兜底需要看图时改走静默直连（不开窗）。
- **跨模块调用**（基础设施用法）：别的模块 `api.use('phone')` 后调 `run({ goal: '一句话任务' })` 或 `run({ flowId: '流程id' })`。跨模块调用落**独立决策会话窗**（`task-*`，互不串上下文），但**动作仍由模块自己执行、每一动都过安全门**——白名单、限速、写操作确认始终是程序约束，不靠任务书文字，也不 spawn 子智能体。定时器自发运行（cron 流程、定时主动逛）走共享的「操作决策」会话窗。
- **定时主动逛**（照刷B站）：面板开「定时主动逛」后，她会在「主动搭话」的醒着时间内按间隔自己逛一轮——AI 按指引库里的**总纲·主流程**自己挑 1~3 个应用签到/刷新内容，跑完私聊汇报主人并写入记忆；受「多久逛一轮」「每天最多逛几轮」两个节奏项约束。

## 怎么用

1. 面板开启模块和总开关；手机开 USB 调试或连上同一台 adb 可见设备（模拟器也行）。想让她自主逛，再开「定时主动逛」并按需调间隔/每日上限。
2. 主人私聊可以直接说「去逛逛手机」「自己刷会儿手机」（走 `phone_auto_browse`），或点名某个已教流程。
3. QQ 里对主人可用：
   - `phone flows` 列流程；`phone flow add <id>` 建流程（**id 只能字母/数字/短横线/下划线，≤40 字**，不支持中文，如 `douyin-signin`；显示名用 `phone flow set <id> name <中文名>` 补）；`phone flow set <id> prompt <做什么>` 教它做什么；`phone flow set <id> triggers 刷B站,签到` 设触发词；`phone flow set <id> cron "0 9 * * *"` 设定时。
   - `phone run <id>` 手动跑；`phone mem <id>` 看记忆；`phone mem clear <id>` 清记忆。
   - `phone status` 看设备/会话/待确认；`phone confirm` 列待批准写操作，`phone confirm 批准 1` 放行。
3. 聊天里说「刷B站」等触发词即可自动接管执行，跑完汇报结果。

## 依赖 adb

本模块依赖 Android 官方 `adb`（platform-tools）：

- 面板「adb 环境」卡片：留空自动探测；「选择本地 adb…」弹系统文件选择框直接挑一个；「扫描本机」列出常见位置的 adb 供选用；「自动安装并选中」从镜像下载 platform-tools（腾讯、Google 中国、Google 官方依次尝试），Windows 自带 `tar` 解压到模块数据目录；
- 「设备」卡片：检测连接的设备（下拉选择），「包名白名单助手」可从手机列出第三方应用一键加入白名单；
- 面板「手机 ADB 调试与首次授权指引」卡片：第一次连手机照着走——开发者选项 → USB 调试 → 弹窗勾「一律允许」点「允许」完成首次授权（不点允许连不上）。

模块**自身只访问** platform-tools 的下载地址（mirrors.cloud.tencent.com / googledownloads.cn / dl.google.com），除此之外不访问任何外部网址；与手机的通信全部走本机 adb。界面节点/截图会作为决策请求发给你配置的模型服务（见「隐私声明」），那不是模块额外访问的网址。

自动安装已按平台区分（Windows/Linux 各自钉死版本 + 官方 sha256 校验，Linux 版解压后自动补 adb 可执行位）——服务器（Linux 无桌面）上不留 adb 也能「自动安装并选中」。

## 服务器部署：远端手机（Tailscale / SSH 隧道）

机器人部署在 Linux 服务器（无桌面）时，手机不用插线：让手机对服务器呈现为一个 `ip:port` 的 adb 网络设备，面板「服务器部署 · 远程设备」卡片输入连接即可——adb 原生支持 `-s <ip>:<port>` 网络序列号，tap/滑动/截屏/强停全部功能与 USB 完全一致，协议侧零改动。模块每次用手机功能前会幂等自动 `adb connect` 一次，adb server 重启导致掉线会自动恢复。

```
手机 (Android)
  ├─[拓扑A] Tailscale + 无线调试 ──tailnet 加密隧道──┐
  └─[拓扑B] 家里电脑同网 + adb tcpip                │
                    └─ ssh -L 隧道（借道家里电脑）──┤
                                                    ▼
                 服务器 (Linux, 无桌面, platform-tools)
                   adb connect <手机IP>:<端口>
```

**拓扑 A（推荐）：手机装 Tailscale，自己进内网**

1. 手机装 Tailscale，登录你的 tailnet。
2. 手机开「无线调试」（设置 → 开发者选项 → 无线调试）。**Android 11+ 的端口是随机的（如 39051），每次开关都可能变——进页面把当前 IP:端口抄下来**，填进面板「连接远程设备」。
3. 服务器 `adb connect <手机tailscale IP>:<端口>`；首次连接手机弹「允许 USB 调试（网络）」授权框，勾「一律允许」。
4. 优点：不依赖家里电脑开机，流量全程 tailnet 加密。手机需常亮充电（熄屏省电可能断连）。

**拓扑 B（备选）：SSH 隧道借道家里电脑**

1. 手机与家里电脑同局域网，家里电脑开 SSH 服务；手机用 USB 连一次家里电脑执行 `adb tcpip 5555`（只需一次）。
2. 服务器建隧道：`ssh -N -L 5555:<手机局域网IP>:5555 用户@家里电脑`（建议常驻）。
3. 服务器 `adb connect 127.0.0.1:5555`；模块侧无感。

**安全红线**：5555/无线调试端口**绝不暴露公网**（adb 网络模式无鉴权）；只用 tailnet 或 SSH 隧道，不要端口转发；Tailscale 建议配 ACL 只放行服务器与手机两台设备；公共 Wi-Fi 下开无线调试有风险（同网设备可扫描 adb 端口），用完随手关。

## 安全默认值

| 项 | 默认 |
|---|---|
| 总开关 | **关**（关着时 AI 工具、触发词、cron、面板运行入口全部停用，只留设置与只读查询） |
| 定时主动逛 | 关（开了也在醒着时间内逛，间隔默认 4 小时、每天默认最多 3 轮） |
| 写操作确认 | 开（发布/评论/点赞等先入队等主人批准） |
| 步数预算 | 40 步/回合 |
| 限速 | 30 动作/分钟 |
| 会话超时 | 15 分钟强断 |
| 包名白名单 | 空 = 不限 |
| 试运行 | 关 |
| 逛完关闭应用 | **开**（回合结束强停本轮到过的应用进程，释放内存） |
| 跨模块调用 | 独立决策窗（task-*），动作同样过安全门（不 spawn 子智能体） |

## 隐私声明

**记忆只存操作经验备注文字，禁止存密码与 Cookie。** 不要在流程描述或记忆里写账号密码、验证码、Cookie；
写了也请立即用 `phone mem clear <id>` 清掉。

**界面内容会发给模型。** 每一步决策都会把当前界面的节点清单（按钮文字、content-desc）发给所选模型；
节点取不到时还会截一整屏发给视觉模型。这些内容只走你配置的模型接口，模块本身不额外对外发送；
不想让某类界面被发出去，就别在那个应用上开流程。
