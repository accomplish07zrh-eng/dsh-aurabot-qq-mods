# 模块目录

这个文件由 `npm run catalog` 生成，不要手改。

每个模块一个文件夹：`modules/<id>/`。格式见 [模块规范](../docs/MODULE_SPEC.md)，第一次提交看 [提交教程](../docs/TUTORIAL.md)。

## 逛平台

| 模块 | 版本 | 作者 | 说明 |
|---|---|---|---|
| [刷抖音](douyin/) | 2.2.0 | Aurabot | 用专用浏览器刷抖音：看推荐、点赞评论，把好玩的视频分享给主人，也能看别人发来的抖音链接。 |
| [刷小黑盒](heybox/) | 1.4.0 | Aurabot | 用主人的账号逛小黑盒：看帖子和热评，点赞、评论、发帖。支持谷时逛、扫码登录和浏览器验证。 |
| [手机逛逛](phone/) | 0.3.0 | Aurabot | 通过 ADB 操控 Android 手机：按主人教好的流程自动签到/浏览/点赞，或自由推理完成一句话任务 |
| [自主上网](rss-reader/) | 1.0.0 | RookieApe-tao | 定时读 RSS 订阅源，把有意思的条目交给主动发言决策（她自己决定要不要跟主人聊） |
| [逛贴吧（只读）](tieba-reader/) | 1.5.0 | GitNekopedia | 只读搜索和浏览贴吧，也可按兴趣向主人私聊分享。 |
| [刷热榜](tophub/) | 0.3.0 | Nightc | 热榜巡游：每天定时逛全网热榜（微博/抖音/知乎/头条等），看完写记忆、挑有意思的私聊分享给主人；对外提供 hot()/search() 热点控件。 |

## 聊天互动

| 模块 | 版本 | 作者 | 说明 |
|---|---|---|---|
| [梗百科](meme-wiki/) | 0.2.5 | Nightc | 本地梗库：聊天里命中就把词条塞进上下文；词条从梗站按需导入，不随模块分发。 |
| [记忆（向量版）](memory/) | 0.4.4 | Nightc | 替换内置记忆，检索名额一半关键词、一半本地向量：字面对不上的旧事也能按意思翻出来。读写仍是同一份 memories.json，卸载即回内置。模型和运行时不随包分发，首次缺文件才联网下载，仅 Windows x64。 |
| [记忆中枢](memory-constellation/) | 0.9.1 | Aureth Labs | 一页管记忆：星图看清晰度和层级，点星复习、改删或新增；内置向量检索、名字联想和可选每日读写，聊天时自动串起相关记忆。 |
