# 模块目录

这个文件由 `npm run catalog` 生成，不要手改。

每个模块一个文件夹：`modules/<id>/`。格式见 [模块规范](../docs/MODULE_SPEC.md)，第一次提交看 [提交教程](../docs/TUTORIAL.md)。

## 逛平台

| 模块 | 版本 | 作者 | 说明 |
|---|---|---|---|
| [刷抖音](douyin/) | 2.0.4 | Aurabot | 用专用浏览器刷抖音：看推荐、点赞评论，把好玩的视频分享给主人，也能看别人发来的抖音链接。 |
| [刷小黑盒](heybox/) | 1.1.2 | Aurabot | 用主人的账号逛小黑盒：看帖子和热评，点赞、评论、发帖。支持谷时逛、扫码登录和浏览器验证。 |
| [逛贴吧（只读）](tieba-reader/) | 1.5.0 | GitNekopedia | 只读搜索和浏览贴吧，也可按兴趣向主人私聊分享。 |
