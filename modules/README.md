# 模块目录

这个文件由 `npm run catalog` 生成，不要手改。

每个模块一个文件夹：`modules/<id>/`。格式见 [模块规范](../docs/MODULE_SPEC.md)，第一次提交看 [提交教程](../docs/TUTORIAL.md)。

## 逛平台

| 模块 | 版本 | 作者 | 说明 |
|---|---|---|---|
| [刷抖音](douyin/) | 2.1.0 | Aurabot | 用专用浏览器刷抖音：看推荐、点赞评论，把好玩的视频分享给主人，也能看别人发来的抖音链接。 |
| [刷小黑盒](heybox/) | 1.3.1 | Aurabot | 用主人的账号逛小黑盒：看帖子和热评，点赞、评论、发帖。支持谷时逛、扫码登录和浏览器验证。 |
| [看直播](kanzhibo/) | 0.3.1 | YG | 用一台独立 Edge 通过 CDP 挂在抖音直播间：进房、进房后发一条定制评论、续粉丝团灯牌；挂着的时候自动暂停刷抖音。 |
| [手机逛逛](phone/) | 0.2.1 | Aurabot | 通过 ADB 操控 Android 手机：按主人教好的流程自动签到/浏览/点赞，或自由推理完成一句话任务 |
| [逛贴吧（只读）](tieba-reader/) | 1.5.0 | GitNekopedia | 只读搜索和浏览贴吧，也可按兴趣向主人私聊分享。 |
| [刷热榜](tophub/) | 0.2.0 | Nightc | 热榜巡游：每天定时逛全网热榜（微博/抖音/知乎/头条等），看完写记忆、挑有意思的私聊分享给主人；对外提供 hot()/search() 热点控件。 |
