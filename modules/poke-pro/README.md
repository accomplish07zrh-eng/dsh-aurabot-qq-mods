# 专业戳一戳（poke-pro）

有人戳她的时候，按权重随机做一件事：反戳回去、让模型回一句、甩个 QQ 表情、发句话、发语音、禁言，或者触发别的插件命令。也支持主动戳、关键词戳和定时戳。

功能对应 [astrbot_plugin_pokepro](https://github.com/galaxy-b612/astrbot_plugin_pokepro)（原作者 Zhalslar 的账号已不可访问，这里以现存 fork 为准），按 Aurabot 的接口重写。

## 它和默认行为的关系

这一点很重要，先说清楚。

Aurabot 芯层本来就处理戳一戳：**有人戳她，她会当成一条对她说的话交给模型**（`hub.js` 里把戳转成 `@你 [戳了戳你]`，同一个聊天 20 秒只算一次）。

本模块挂的是 `poke` 事件，芯层在**默认处理之前**先问模块：

```js
// src/chat/hub.js:1595
if (hooks?.poke) {
  try { if (await hooks.poke(ev)) return }   // ← 返回 true 就直接 return
  } catch (error) {}
}
```

所以：

- **返回 `true`** = 这条戳由模块接管，芯层不再走默认的 LLM 处理
- **返回 `false` / 不返回** = 交回芯层，行为和没装模块一样

模块在这几种情况下会交回芯层，让她正常回：

| 情况 | 行为 |
|---|---|
| 模块被关掉 | 交回芯层 |
| 所有动作权重都是 0 | 交回芯层 |
| 动作执行报错 | 交回芯层（让她至少还能正常说话） |

反过来，**冷却期内重复戳也会返回 `true`**——意思是「我已经知道了，但这次不再动作」，避免芯层又走一遍 LLM 把她惹烦。

> 如果你只想要原来的默认行为，把 `enabled` 关掉即可。

## 配置

面板会自动生成表单。改完立即生效，不用重载模块。

### 基础

| 项 | 默认 | 说明 |
|---|---|---|
| 启用 | 开 | 关掉则完全不干预 |
| 被戳冷却（秒） | 10 | 同一聊天内重复戳只处理一次，防连戳 |
| 跟戳概率 | 0.1 | 看到**别人**被戳时，跟着戳一下的概率；0 = 不跟 |

### 回复动作（按权重随机）

概率 = 本权重 ÷ 所有非零权重之和。**权重填 0 等于关掉这个动作。**

| 动作 | 默认权重 | 做什么 |
|---|---|---|
| 反戳 | 10 | 戳回去，次数在 1～「反戳次数上限」之间随机 |
| LLM 回复 | 10 | 带人格和上下文想一想，然后把话发出来 |
| QQ 表情 | 10 | 从表情池随机挑一个，按「最大复制数」连发几个 |
| 表情包 | 30 | 有本地图库就发图，没有就发文字池里一句 |
| 语音 | **0**（关） | 从语音池随机发一个音频文件 |
| 禁言 | 10 | 群里禁言（时长 = 基础 ± 波动）；私聊没法禁，回退到表情 |
| 触发命令 | 10 | 从命令池随机发一条，交给别的插件处理 |

LLM 模板里可以用 `{username}`，会被替换成对方的**群名片 → 昵称**（拿不到就退到「某人」，不会把 QQ 号亮出来）。

### 主动戳

| 项 | 默认 | 说明 |
|---|---|---|
| 主动戳次数上限 | 5 | `/戳 @某人 45` 时非主人会被夹到这个值，主人不受限 |
| 发戳间隔（秒） | 0.5 | 连戳之间的间隔，防风控 |
| 关键词触发戳 | 笨蛋,人机,机器人,bot | 消息含这些词就戳一下说话的人 |

### 定时戳

| 项 | 默认 | 说明 |
|---|---|---|
| 启用 | 关 | |
| 定时表达式 | `30 22 * * *` | 分 时 日 月 周，支持 `*`、数字、逗号、范围、`*/n` 步长 |
| 定时戳目标 | 空 | 一行一个，格式 `群号:QQ号` |
| 定时戳次数 | 1 | |

Aurabot 没有 cron，模块用「每分钟醒一次 + 表达式匹配」实现，同一分钟不会重复触发。

## 命令

主人在 QQ 里发（`/戳` 认主人，别人发当普通消息）：

| 命令 | 说明 |
|---|---|
| `/戳 @某人 [次数]` | 戳指定的人，次数受上限约束 |
| `/戳我` | 戳自己 |
| `/戳全体成员` | 戳全群；超过 200 人时随机抽 200 个 |
| `/戳状态` | 看当前权重分布和开关情况 |

## 面板参数的写法

| 设置项 | 写法 |
|---|---|
| QQ 表情池 | 表情 ID，逗号或空格分隔，例如 `4,14,15,21` |
| 表情包文字池 | 一行一条 |
| 本地图库路径 | 一行一个目录或文件路径（`api.sendImage` 能接受的都行） |
| 语音文件池 | 一行一个音频文件的绝对路径 |
| 命令池 | 逗号或换行分隔 |
| 定时戳目标 | 一行一个 `群号:QQ号` |

格式写错的行会被**丢掉**，不会让整个模块起不来。

## 会访问哪里

- **不联网到任何第三方**。所有网络请求都走 Aurabot 已有的 QQ 网关（`api.onebot`）。
- 发的图 / 语音是你自己配的本地路径。
- 不读写 Cookie，不碰消息内容之外的任何数据。

## 已知限制

- **表情包没有 meme_generator**。AstrBot 版可以套模板生成表情包（拍一拍、吃……），Aurabot 没有对应能力，所以这里只有两条路：发你配的本地图，或者发文字池里一句话。想要动态生成，得另外接一个生图服务。
- **禁言只在群里有效**，私聊会回退成表情。
- **跟戳只在群里**。私聊场景「别人被戳」没有意义。
- **定时戳最小粒度是分钟**，且依赖模块活着（模块停用就不跑）。
- 参考项目的「头像类模板」相关配置（头像缓存、内存压力阈值等）在本模块里没有对应实现，属于故意省略——没有生成器，那些缓存没东西可缓存。
