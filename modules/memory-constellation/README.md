# 记忆中枢

Aurabot 用户模块：三级记忆星图 + 记忆向量 + 记忆联想 + 可选每日读写。

星图直接读取内置记忆，不建第二套记忆库；已有的记忆安装后会自动同步，不需要导出导入。记忆增强把「按意思找」「按名字串关系」和「每日读写」放在同一张卡的三个页签里。每日读写默认关闭：新记忆的写入和整理由内置记忆负责，自动回忆、归档和删除由记忆中枢负责；需要中枢也提炼时再打开总开关。

## 安装

插件 1.2.0 起支持模块市场：打开 Aurabot 面板的「模块市场」，找到「记忆中枢」，确认来源、版本和能力清单后安装。

- 安装完成后打开「扩展」页确认「记忆中枢」已加载，再打开面板，等 3 秒左右首次同步完成。
- 如果之前装过旧的「记忆增强」（`memory-assoc`），先在「扩展」页移除它，否则两个模块会重复注入提示。
- 手动安装：把 `memory-constellation` 文件夹放进 Aurabot 数据目录的 `modules\` 下，通常是
  `%USERPROFILE%\.dsh\plugins-data\aurabot\modules\memory-constellation`。

## 已有记忆会自动同步

记忆中枢只读内置 `memory` 模块，星图的每颗星都对应一条已有记忆。

- 安装后首次启动约 3 秒同步一次，星图、层级列表、联想边都会基于现有记忆重建；
- 如果打开面板时还没同步，点一下星图卡右上角的「刷新」，或重新打开面板；
- 如果星图是空的，先确认 Aurabot 的「记忆」模块已启用，并且库里确实有记忆。

注意：这里的「同步」是指读取这台 Aurabot 自己的内置记忆。本模块不提供把另一台机器、另一个人的记忆数据导进来的功能；不要在测试者之间直接传 `memories.json` 或 `config.json`。

## 面板怎么用

- **记忆星图**：默认显示星图。点「展开星图设置」可调回看、快照、自动旋转、辉光、关系线和显示类型。清晰度过低、被内置整理归档的记忆固定在上方的「归档星云」，点开可以恢复。
- **记忆增强**：默认折叠。展开后有三个页签：
  - 「记忆向量」：按意思找，包含相似度门槛、补条数、检索测试、补算/全部重算；
  - 「记忆联想」：按名字串关系，包含概率、门槛、跳数、条数、强化强度、称呼实体、联想测试和重建；
  - 「每日读写」：默认关闭。打开后才读取聊天/群聊/经历并分批提炼写入；面板里可以调触发条数、每日写入上限、每批条数、自动归档和素材保留。
- **层级记忆**：默认折叠。展开后可按临时/长期/永久筛选，新增、编辑、换层或删除单条。
- 星图详情里的「删除」会删除内置记忆本体，测试时请先用不重要的记忆。

## 用量模式

「记忆增强」顶部有四档可选，切换后点底部统一保存：

- **只看星图**：不注册召回工具、不注入提示，星图、层级和归档照常可用；
- **省 Token**：只认名字联想，回复最多 3 行，适合日常；
- **标准**：名字联想 + 问题向量联想，回复最多 3 行；
- **深度**：提高联想概率和条数，最多 5 条，适合重要阶段。

四档只影响后续调用，不重写记忆、不重跑整理、不改层级和归档状态；面板显示的 token 只是参考估算，没有硬性上限，也不会自动停止。老用户升级时会按现有参数推断一个模式，不会重置原来的设置。

打开「每日读写」后，四档也会影响它：只看星图不调用模型提炼；省 Token 攒到 40 条才提炼；标准默认 20 条；深度 15 条。关闭时四档只影响聊天侧召回。

## 自动回忆（默认由中枢接管）

记忆中枢会自动关闭内置记忆的每轮召回（`autoRecall:false`），把自动回忆统一成一段提示：

- **直接混合召回**：关键词一半 + 向量一半，默认最多 4 条；
- **名字联想**：人物、标签、相似、冲突，最多 3 条；
- **问题联想**：问句向量种子 + 一跳；
- 合并去重后只生成一段「你记得这些事」，总字数默认上限 420。

需要「记忆（向量版）0.4.4+」提供 `setAutoRecall`。原版内置记忆没有这个开关时，中枢只做关系联想，内置照常召回。中枢停用或关闭「自动回忆由记忆中枢接管」后，内置恢复原来的混合召回。

中枢面板顶部会显示状态：自动回忆、写入与整理、遗忘分别由哪个模块负责；降级时也会说明为什么没有接管。

## 每日读写（默认关闭）

「记忆增强」的第三个页签，默认不运行。关闭时：

- 新记忆的写入、提炼、人物小档案、相处经验、说话方式都由内置记忆负责；
- 中枢负责判断归档、执行归档和删除，并展示归档星云、支持恢复；
- 需要手动补整理时，用内置记忆面板的「现在整理一次」。

打开总开关后，这一页才额外负责读取活动和提炼写入：

- **读取**：接收私聊、允许的群聊，以及来源是经历/日记/空间的活动，按 messageId 去重；
- **提炼**：攒够门槛后分批调用模型，提出事实、喜好、身份、约定和重要经历；
- **写入**：低重要度写进临时层，重要度高写进长期层；重复内容由内置记忆去重和强化。写入额度随当天聊天量自动提高（最多 30 条），重要度高的要点另有额度，没写完的会排队到后面继续写；
- **巩固**：反复提到会提高巩固度和层级，临时 → 长期 → 永久；
- **归档**：本地扫描清晰度过低的非永久记忆，进入归档星云；
- **清理**：归档满 30 天、过时满 180 天的条目删除。

如果本机已经有同类每日整理模块在运行，这一页会自动待命，不重复读取和提炼。

## 归档星云

记忆中枢每约 30 分钟按遗忘曲线扫描一次：清晰度过低的长期记忆（重要度低于 60%、清晰度低于 5%、巩固度低于 1.5）和到期没再想起的临时记忆会归档；永久记忆不参与自动归档。归档条目不进入聊天召回，也不再画关系线，统一固定在星图上方，用灰色虚线环标出。

- 点开归档星，详情里有「恢复这条记忆」；恢复后回到原星团，并按当前层级重新计算清晰度；
- 归档满 30 天、过时满 180 天由记忆中枢删除；
- 中枢接管时，内置记忆停止自己的归档和删除；中枢停用或关掉「归档与删除」后，内置记忆自动恢复；
- 需要「记忆（向量版）0.4.4+」提供接管标记；原版内置记忆没有这个标记时，中枢只展示，归档/删除仍由内置记忆负责；
- 归档数据本来就在 `memories.json` 里，备份时会一起带走。

## 数据搬家（备份 / 恢复）

模块市场安装不带导出导入脚本，直接备份数据目录即可：

1. 完全退出 Aurabot；
2. 备份 `plugins-data\aurabot` 下的 `modules-data\memory`、`modules-data\memory-constellation`，以及记忆正文 `memories.json`；
3. 换机器时把这几份复制到新机器的同一位置，再启动 Aurabot。

数据包里是记忆正文、向量索引、星图状态和联想关系，只用于自己的数据搬家，不要发给别人。

## 数据与隐私

- 声明能力：`filesystem`、`plugin-config`、`plugin-internals`；依赖内置 `memory` 模块。
- 读取：内置记忆条目、人物小档案、Aurabot 配置里的主人/人格称呼。
- 写入：`modules-data\memory-constellation\state.json`、`assoc.json`；Aurabot 配置里的本模块设置（含接管标记）；用户主动触发的复习、新增、编辑、删除、换层；中枢接管遗忘时写 `memories.json` 的归档状态，并删除满期条目。
- 本模块不直接联网、不需要 API Key；「每日读写」的提炼使用 Aurabot 里已配置的模型。
- 模块包只含代码和文档，不含任何人的配置、记忆或日志。
- 卸载：在「扩展」页停用或删除 `modules\memory-constellation`；数据仍保留在 `modules-data\memory-constellation`，需要彻底清理时再手动删除该目录。中枢接管后停用，内置记忆会自动恢复自己的召回和遗忘逻辑。

## 常见问题

**扩展页没有「记忆中枢」**
先确认模块已通过「模块市场」或手动装到 `modules\memory-constellation`；确认 Aurabot 数据目录正确；重新加载扩展页。

**星图空白**
确认「记忆」模块开着且已有记忆；点「刷新」；如果仍空白，把 `logs` 里最后 30 行和截图发回来。

**向量显示未运行**
向量是记忆内核的可选能力，模型/索引没准备好时星图和联想仍可用；可以稍后再点「刷新状态」。

**设置像是不见了**
记忆星图设置、记忆增强、层级记忆都默认折叠，点各自的「展开」按钮即可；不是功能被删。

**旧「记忆增强」还在**
在「扩展」页停用或删除 `memory-assoc` 后再重新加载，否则会重复注入提示。

**记忆很多时卡顿**
超过 6000 条时，缩小的全景图里普通星点会自动用尘埃点绘制，放大后恢复逐颗可点；面板自动刷新间隔也会随记忆量拉长。低配电脑还可以在星图设置里关掉「辉光」、关系线改成「只在选中」，或把「最多常驻线」调低。


日志在 `%USERPROFILE%\.dsh\plugins-data\aurabot\logs\`。不要发记忆正文、完整 `config.json` 或账号凭据。
