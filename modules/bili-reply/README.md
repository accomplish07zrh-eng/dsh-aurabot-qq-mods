# B站回动态评论

回她自己 B 站动态下面的评论：读评论 → 让她写一句 → 发出去。

## 做什么

- 定时看她最近几条动态的评论区（走 B 站接口，不开浏览器）
- 挑出还没回过、也不是她自己发的评论
- 回复内容让她自己写（一两句、口语、30 字以内，不要「感谢支持」这种客套）
- 同一条不会回两次；有每天上限和两轮间隔
- 默认**只读不回**（试运行），确认能正确找到评论后再关掉

## 怎么用

1. 先在 Aurabot 面板「B站」页登录 B 站
2. 动态从哪来：如果同时装了 `bili-dynamic`，自动用「她最近发过的动态」；没装就在设置里手填动态链接，一行一个
3. 默认只读不回，点「看看有没有新评论」先看它找到什么

## 会访问什么

- B 站接口：`api.bilibili.com` 的读评论和发回复接口（GET / POST）
- 只读插件配置里的 B 站登录 Cookie（`plugin-config`），不发往别处

不刷量：每天最多回几条，两条之间默认隔 20 分钟，主人可随时关掉。
