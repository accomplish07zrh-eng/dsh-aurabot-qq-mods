# 去 AI 味

把「作为 AI」「总而言之」「希望对你有帮助」「欢迎随时问我」这类客服腔从她发出的消息里清掉；顺便认出模型写的「这次不说话」记号（`[沉默]`、`[silence]`、`（不回）`、`skip` 等），整句只有记号时就不发。

## 做什么

- 出站前改写文字：去掉 AI 自称、客套收尾、总结腔、起手铺垫
- 整句都是客服话时保持沉默，而不是发一句空话
- 识别多种「不说话」写法（中文 / 英文 / 带括号 / 带标点）
- 只处理文字：表情、语音、引用不受影响

## 怎么用

装上就生效，设置里可以单独关掉。

## 会访问什么

不联网、不读写文件、不碰账号配置。只处理插件交给你的文字。
