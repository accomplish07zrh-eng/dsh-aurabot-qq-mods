# 微博（Aurabot 扩展）

给 [Aurabot](https://github.com/accomplish07zrh-eng/dsh-aurabot-qq) 加微博能力：查热搜、扫码登录、读自己的微博、发博/转发/评论。

写操作默认**试运行**（只回一句"会发什么"，不真发），确认无误再开。删除操作需要二次确认（`/删微博 <id> 确认`）。

## 安装

需要 **Aurabot 1.2.0 或更高版本**（模块市场从 1.2.0 开始）。

- **模块市场**：Aurabot 面板 →「扩展」→ 搜「微博」→ 安装
- **手动**：把本目录复制到 `~/.dsh/plugins-data/aurabot/modules/weibo/`，再到面板「扩展」里重新加载

装好后侧栏会多出「微博」标签页，面板里还有一个图形面板（二维码、档位按钮、用量条）。

### 更新 / 卸载

- 更新：在模块市场里点更新（或手动覆盖目录）。**登录态、设置、用量计数在 `modules-data/weibo`，更新不会清空**。
- 卸载：市场里卸载，或删掉 `modules/weibo` 和 `modules-data/weibo` 两个目录。

## 第一次使用：登录

面板「微博」页 → 第一项「⚡ 快捷操作」→ 选 **① 登录微博**。它会按环境自动选方式，**都不需要你复制任何东西**：

| 环境 | 行为 |
|---|---|
| 有图形桌面 | 直接弹出一个微博登录窗口，你在窗口里扫码/输账号，完成后自动关闭并保存 |
| 无桌面（服务器） | 把登录页二维码截图私聊发给你，手机微博扫一下即可 |

也可以直接发 `/微博登录`，效果一样。

背后做的事：起一个独立 profile 的 Chrome（`modules-data/weibo/browser/`，与你日常浏览器隔离）→ 打开 `passport.weibo.com` 登录页 → 每 2 秒轮询 cookie，出现 `SUB` 即登录成功 → 存进 `cookies.json`（权限 600）→ 关窗口。

**备用：粘 Cookie**（只在扫码被风控挡住、或你已有现成会话时用）

1. 电脑浏览器登录 [weibo.com](https://weibo.com) → `F12` → **Network** → 刷新 → 任选一条 `weibo.com` 请求 → **Request Headers → Cookie** 整行复制
2. 发 `/微博导入 SUB=xxxx; SUBP=yyyy; ALF=zzz; XSRF-TOKEN=www`

> 只复制 `SUB` 不够，微博会判定未登录，至少要 `SUB` + `SUBP`。

| 字段 | 作用 | 有效期 |
|---|---|---|
| `SUB` / `SUBP` | 登录凭证 | 约 1 年 |
| `ALF` | 会话辅助 | **约 1 个月**（所以一个月左右要重登） |
| `XSRF-TOKEN` | 写操作防伪头 | 随会话 |

## 三档预设

面板上点，或在 QQ 里发 `/微博设置 安全|正常|全开`：

| 档位 | 试运行 | 间隔 | 每天上限 |
|---|---|---|---|
| 🟢 安全 | 开 | 30 分钟 | 2 条 |
| 🟡 正常（默认） | 开 | 10 分钟 | 5 条 |
| 🔴 全开 | **关** | 5 分钟 | 15 条 |

「全开」会真的发出去，切档时会二次确认，面板顶部会显示红色警示条。

## 命令（只认主人）

| 命令 | 作用 |
|---|---|
| `/热搜` `/热搜 20` | 微博热搜榜 |
| `/我的微博` `/我的微博 120` | 读自己最近的微博（**会翻页**，上限 500 条） |
| `/找微博 关键词` | 在自己全部历史微博里搜（找很多年前那条用这个） |
| `/TA的微博 <主页链接或uid> [条数]` | 读某个人的微博 |
| `/看微博 <链接或id>` | 读某条微博正文 |
| `/看评论 <链接或id>` | 读某条微博的评论 |
| `/发微博 内容` | 发一条微博 |
| `/转发 <链接> #说点什么` | 转发 |
| `/评论 <链接> 内容` | 评论 |
| `/删微博 <微博id>` `/删评论 <评论id>` | 删自己发的 |
| `/微博状态` | 登录态 + 今日用量 + 当前生效配置 |
| `/微博设置 安全\|正常\|全开` | 一键切档 |
| `/微博登录` `/微博导入` `/微博登出` | 登录管理 |
| `/微博帮助` | 一步步的上手指引 |

## 工具

`weibo_hot`、`weibo_my_posts`（支持 `keyword` 搜历史）、`weibo_user_posts`、`weibo_read_post`、`weibo_read_comments`、`weibo_status`、`weibo_post`、`weibo_comment`。

群聊里只挂**只读**工具；发博/评论这类写操作只在主人私聊可用。

## 设置项

面板「微博」页可调，每项都有小字说明：

| 设置 | 默认 | 说明 |
|---|---|---|
| ⚡ 快捷操作 | — | 登录 / 退出 / 看状态，选完自动复位 |
| 微博功能开关 | 开 | 只管本模块（和面板顶部管整个机器人的「总开关」不是一回事） |
| 当前档位 | 正常 | 选完立刻套用间隔/上限/试运行 |
| 试运行 | 开 | 关掉才真的发 |
| 两次操作最小间隔 | 10 分钟 | 防验证码 |
| 每日上限 | 5 / 5 / 5 | 发博/转发/评论，各自独立，UTC 零点清零 |
| 热搜条数 / 读微博条数 | 10 / 10 | 不带参数时的默认值 |
| 热搜定时私聊 | 0（关） | 大于 0 时每 N 小时私聊一条热搜 |
| 登录方式 | 自动 | 有桌面就弹窗，没桌面发二维码；失败时可改「纯接口」 |
| 浏览器路径 | 留空 | 扫码用的 Chrome；留空自动找 |

## 安全与风控

- 写操作受三重限制：功能开关 → 每日上限 → 最小间隔，任一不满足都会拒绝并说明原因
- 微博要求验证码/操作频繁时，自动**当天停手**并私聊告警，第二天恢复，不会硬试
- Cookie 存在 `modules-data/weibo/cookies.json`（600），不进插件配置、不被状态接口回显
- 建议用小号做自动化

## 已知限制

- **标签页绿点**：模块定义里声明了 `flag: 'loggedIn'`，看的是 `ext.weibo.loggedIn`（Aurabot **1.2.0+** 支持，见 [#166](https://github.com/accomplish07zrh-eng/dsh-aurabot-qq/issues/166)）。更早的版本不显示绿点，其余功能不受影响——登录状态在面板里照常可见。
- **扫码登录**需要系统里有 Chrome/Chromium；没有图形界面时依赖 `xvfb-run`。
- 微博网页接口是逆向的，微博改版可能需要跟着更新。
