# 星露谷（stardew）

让鱼自己在《星露谷物语》里种田：**判断是她自己做的**，模组只负责把画面翻成文字、把她发的动作执行掉。

## 这个模块基于下面这个插件开发

- **原插件仓库**：<https://github.com/Darianliu23/dsh-stardew-blind-whale-farmer>
- 作者：Darianliu23（大肥鱼种白饭 / Blind Whale Farmer）
- 本模块基于该插件的 **SMAPI 模组**（`BlindWhaleFarmer`，负责游戏内动作与 MCP 服务器）开发，
  但**没有**直接复用它的 DSH 插件层（那部分是「DSH 会话预设 + 入口工具」，结构不同）。
  本模块按 aurabot 的模块接口重写了一遍：同样的 MCP 协议、同样的工具名，接法换成 aurabot 的。

安装游戏侧内容仍然是照原插件的说明走：装 SMAPI → 把 `BlindWhaleFarmer` 放进 `Mods` → 启动一次游戏。
本模块只负责 aurabot 这一侧。

## 它在做什么

```
我（后台会话）──stardew_game 工具──> 模组 MCP（127.0.0.1:18080）──> 游戏里执行（寻路/浇水/钓鱼…）
        ↑                                                                    │
        └──────────────────── 文字状态（get_state）──────────────────────────┘
```

- 模组把画面翻译成纯文字（时间、体力、背包、坐标地图、作物、附近物体），**不需要视觉模型**；
- 鱼自己看状态、自己决定干什么，再发高层动作；
- 跑完整一局（几轮）以后只往私聊发**一条**总汇报。

## 怎么用

| 方式 | 说明 |
|---|---|
| `/自己玩 10` | 让她自己玩 10 分钟（只写数字；不写默认 30） |
| `/收工` | 叫停，这一轮做完就收 |
| `/星露谷` | 查连通性（游戏开着没、MCP 通没通） |
| 私聊里 `stardew_peek` | **只读**：问「农场怎么样了/笔记写了啥」看一眼，不会动手 |

## 设计上刻意做的几件事

1. **玩游戏的活儿只在后台会话（`system:stardew`）里干**。那个会话只挂 `stardew_game` 一个工具，
   人格还是全局那份，所以「还是她」，不是另一个 AI。私聊里不挂完整工具，避免她手痒自己开一局。
2. **汇报只发一条，且用 OneBot 直发**。早期用 `pushToSession` 会往会话塞"用户消息"，她得再想一轮，
   排队久了汇报会积压、时间线倒序；用 `api.sendText` 又会被出站策略当主动发言拦掉。
3. **只看硬证据**：存档是否真的更新（比 `Saves/<存档>/<存档>` 的 mtime）、游戏进程是否真的关了、
   模组 MCP 是否真的通了。后台那轮模型的自述只作参考——它会瞎编过程。
4. **自己起游戏、自己关游戏**：`stardew-launch.ps1` 负责拉 `StardewModdingAPI.exe`、抢窗口前台、
   按比例坐标点「加载」和存档行；收工后 `sleep` 存档再关进程。

## 设置项

| 键 | 说明 |
|---|---|
| `port` | 模组 MCP 端口，和模组 `config.json` 的 `McpPort` 一致，默认 18080 |
| `gameDir` | 有 `StardewModdingAPI.exe` 的那个文件夹 |
| `timeoutMinutes` | 单个动作最多等几分钟（钓鱼、下矿很长） |
| `selfPlayGapMin` | 自己玩时两轮之间歇几分钟 |
| `allowOthers` | 允许群聊/别人用只读工具（默认关） |

## 已知坑（都踩过并修了）

- **SMAPI 不热加载模组**：装完必须重启游戏，否则 MCP 端口不通。
- **游戏停在标题画面**：MCP 已经在听，但 `get_state` 会回「游戏还没有进入存档（在标题画面或正在加载）」。
  判断进没进存档要匹配这句原文（少一个字就会永远判错，之前就是这么假成功的）。
- **`pauseWhenOutOfFocus`**：游戏设置里这项开着时，窗口被别的程序挡住会整个冻结，看着像在玩其实时间不动。
  本模块装好后请把它关掉（游戏设置 → 「窗口不活动时暂停」）。
- **模组 `PauseWhenAiStops`**：同理，介意的话在模组 `config.json` 里设成 `false`，并把 `McpIdleSeconds` 调大。
- **按 F8** 启动的是模组自带的 AI，和本模块抢操作，会提示先停掉它。
