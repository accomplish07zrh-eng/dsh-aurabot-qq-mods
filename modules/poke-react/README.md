# 小动作（戳回去 · 表情回应）

被戳一戳会戳回去；看到消息偶尔给那条消息贴个表情回应。

## 做什么

- 有人戳她：按概率戳回去（默认 90%，等半秒到两秒才戳，不像机器人）
- 看到消息：按概率给那条消息贴个表情回应（赞 / 贴贴 / 爱心这类）
- 太短的消息、点名找她的消息不贴，免得抢了正常回话
- 心情不好（生气 / 失落）时不贴表情；心情好时概率提高
- 每小时有上限（默认 6 次），不会刷屏

## 怎么用

装上就生效，设置里能调两个概率和每小时上限。

## 会访问什么

- 走插件已有的 OneBot 调用：`send_poke`（戳回去）和 `set_msg_emoji_like`（贴表情）
- 网关不支持 `set_msg_emoji_like` 时只在日志里记一句，不影响别的功能

不联网、不读写账号配置、不发消息内容。
