# B站

让她自己逛 B 站。不是简单的「查个视频」，是像人一样刷、看、评论、互动。

这是插件内置 B站 模块的**独立增强版**，装上会替换内置的（`replacesBuiltin: true`）。

## 做什么

**看别人发来的视频**

发一个 B 站链接给她，她会看：

- 标题、UP 主、简介、播放量
- 字幕（有的话）
- 热门评论
- 抽帧看画面（需要 ffmpeg，可选）

**自己去刷**

- 按作息定时刷首页推荐
- 自己挑想看的（不是全看）
- 写「鱼日记」：今天看了什么、为什么挑中、有什么感受
- 出日报：一天看了什么、评论了什么、发了什么弹幕

**互动**

- 评论视频（带风格守卫，不会说废话）
- 回评论区的回复
- **评论区 @ 我**：别人 @ 她时自动回复（可关）
- **私信**：主人的 B 站私信，单独一条定时器，不受作息窗口限制
- 发弹幕（可选，带查重）
- 点赞 / 收藏（有每日上限和冷却）

**其它**

- 抽帧看画面（`bili_watch` 的 vision 能力）
- 发截图给她（`qq_send_shot`）
- 按权限改自己的 B 站头像 / 签名
- 风控识别：遇到验证码自动暂停，不硬闯

## 怎么用

### 先登录

面板「B站」页扫码登录，或者粘贴 Cookie。

### 工具

装了以后她会多这些工具：

| 工具 | 作用 |
|---|---|
| `bili_watch` | 看一个视频（标题/简介/字幕/热评，可选抽帧看画面） |
| `bili_comment` | 评论一个视频 |
| `bili_danmaku` | 发弹幕 |
| `qq_send_shot` | 发截图 |
| `bili_set_avatar` | 改 B 站头像 |
| `bili_set_sign` | 改 B 站签名 |

### 面板

面板「B站」页有：登录、刷视频设置、互动设置、私信设置、日报、截图、历史。

## 会访问哪些网址

**只访问 B 站自己的接口**：

- `api.bilibili.com` — 视频信息、评论、点赞、收藏
- `api.vc.bilibili.com` — 私信
- `www.bilibili.com` / `t.bilibili.com` — 网页接口
- `i0.hdslb.com` / `i1.hdslb.com` / `i2.hdslb.com` — 图片、视频封面、弹幕
- B 站视频 CDN（抽帧时要下载视频片段）

**不访问任何其他域名。** 没有第三方统计、没有上报。

## 隐私

- Cookie 只存在本机 `plugins-data/aurabot/config.json`，不外发
- 刷到的视频、评论、私信只存在本机 `plugins-data/aurabot/`
- 不会把数据发到 B 站以外的任何地方
- 私信默认只处理主人发的（`dmOnlyOwner`）

## 行为约束（防止刷量）

- 评论、回复、点赞、收藏、弹幕都有**每日上限**
- 点赞有**冷却时间**，不会连续猛点
- 请求之间有**节流间隔**（默认 1 秒）
- 遇到验证码**自动暂停**，不绕过
- 试运行模式（`dryRun`）下只记录不真发

## 需要什么

- Aurabot 插件 1.2.0 或更高
- 一个 B 站账号（扫码登录）
- 可选：ffmpeg（抽帧看画面）
- 可选：`memory` 模块（记住刷到的东西）

## 数据在哪

- 状态：`plugins-data/aurabot/bili.json`
- 历史：`plugins-data/aurabot/bili-history.jsonl`
- 点赞记录：`plugins-data/aurabot/bili-likes.jsonl`
- 鱼日记：`plugins-data/aurabot/bili-diary.jsonl`
- 日报：`plugins-data/aurabot/bili-reports/`
- 截图：`plugins-data/aurabot/bili-shots/`
- 验证状态：`plugins-data/aurabot/bili-verify.json`

## 与内置模块的关系

本模块 `replacesBuiltin: true`，装上后替换内置 B站。想用回内置的：面板「已安装」页那一行切「用内置的」，或者删掉 `modules/bili/` 文件夹。

## 第三方

内置 B站 模块的原始实现来自 Aurabot 插件（MIT）。本模块是它的独立增强版，把插件内部依赖（`src/bili/`、`src/core/`、`src/chat/` 的部分函数）内联到了 `lib/`，所以能独立分发。
