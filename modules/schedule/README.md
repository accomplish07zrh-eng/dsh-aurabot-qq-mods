# 她的一天

给她排一张 24 小时的时间表（几点在干嘛、忙不忙），聊天时她知道「自己这会儿正在做什么」，而不是永远只会在屏幕前等消息。

## 做什么

- 每天早上用一次很短的模型调用，按当前人格排出当天 6～10 段日程，首尾相接覆盖 00:00–24:00
- 每段带 `activity`（在干嘛）和 `availability`（`sleeping` / `busy` / `idle`）
- 每轮聊天前往提示词里加一句：「现在是 21:30，你正在打游戏（闲着，可以多聊两句）」
- 被问到「在干嘛」时照实说；忙的时候自己会说得短一点

排失败时用一份保底日程，不会因为模型抽风就整天空着。

## 怎么用

装上就生效。设置里可以关掉。

想让别的模块知道她这会儿忙不忙，可以 `api.use('schedule')`：

```js
const schedule = api.use('schedule')
if (schedule?.availability?.() === 'sleeping') return // 她在睡，别去打扰
```

导出：`plan()` / `slot()` / `availability()` / `ensurePlan()`。

## 会访问什么

- 读当前人格全文（`api.core.personas.current()`）——只为了让她的一天符合她自己的设定，不外发
- 调一次插件已有的模型接口（`api.ask`）排日程
- 数据只写在模块自己的目录里

不联网抓取、不读写账号配置、不碰 QQ。
