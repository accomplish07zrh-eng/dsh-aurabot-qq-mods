# 看直播（kanzhibo）

给大肥鱼加的本事：在抖音直播间「挂着」，顺便把该做的事做掉。

## 干什么

1. **进直播间**：用一台独立的 Edge（自己的 profile，不动你平时的浏览器）通过 CDP 挂进直播间。
   给直播间地址最稳；给主播主页（`douyin.com/user/...`）会自己找「直播中」点进去。
2. **和刷抖音互斥**：进房期间把 `douyin.enabled` 关掉，离开 / 关掉挂直播后自动放回来
   （放回来之前先晾 10 分钟，免得两个浏览器抢同一个 profile）。
3. **进房评论**：页面真的渲染出评论框之后再发一条你定的评论，一天一次。
4. **续灯牌**：先看「今日任务」里灯牌那行是不是「已完成」，没送才点左上角的粉丝团送一次，送完再判定一次。
   今天这个直播间确认送出过就跳过（不再重复点、不再刷日志）。
5. **在 QQ 里用**：`/看直播 开|关|状态|进|收工|自检`，以及她自己的工具
   （`kanzhibo_enter` `kanzhibo_status` `kanzhibo_stop` `kanzhibo_say`；
    `kanzhibo_gift` 要多一道锁：面板里「QQ 私信送礼」打开、而且是在你的私聊里，她手上才有这个工具）。

## 自检

QQ 里发 `/看直播 自检`（或面板里调 `/aurabot/api/ext/kanzhibo/selfcheck`）会回一份体检单：
浏览器路径、专用 profile、CDP 端口、时段在不在内、刷抖音暂停状态、今日评论 / 灯牌是否已完成、最近一条日志。

## 离线自检脚本

```
node test/verify.mjs                              # 只测逻辑：74 项（注册、主人权限、送礼开关、时段、去重、崩溃恢复、面板渲染）
set LIVE=1 && node test/verify.mjs                # 再加测真浏览器 + CDP
```

脚本给模块喂一个假的 `api`：不发 QQ、不改真配置、数据落在临时目录。

## 0.3.1 修掉的毛病（2026-11-05）

- 群里谁都能让她去挂直播：进房 / 停止 / 送礼 / 说话这四个工具原来在群聊里也挂着，
  而且只有送礼和代发看了主人身份。现在按「这一轮有没有主人说话」判断（`turnHasOwner`），
  别人只剩状态查询，状态里也不显示在看谁、当前地址。
- 冷却定时器被无限推后：`tick()` 每轮都调一次「10 分钟后再放开刷抖音」，每次都重排定时器
  并打一条「直播间刚关」，冷却永远到不了点（刷抖音一直关着），日志凌晨每 2 分钟一条。
  现在冷却期内直接返回，不重排也不重复打日志。
- `ensureInRoom()` 在 CDP 已经掉线时拿 `null` 调 `cdp.close()` 会抛 TypeError，改成判空。

## 0.3.0 修掉的毛病（2026-11-04）

- 崩溃恢复成了死代码：`resumeDouyin()` 开头有「没暂停过就早退」的守卫，
  加载时那条「上次是挂着直播停的，这次把刷抖音放回来」永远走不到 → 刷抖音一直关着。
  现在先把内存标记立起来再走正常恢复。
- 续灯牌点错地方：找「粉丝团/灯牌」没限长度，一个包住整页文字的大容器也能匹配，
  结果点到了顶部导航（日志里那条「点了『精选 推荐 AI抖音 关注 朋友 我的』」）。
  现在只认短文字、靠左上、面积最小的元素，二次确认也只在那块面板里找。
- 灯牌成功后每 2 分钟重复打一条「今天已经送出了」刷满日志 → 当天同一直播间直接跳过。
- 检查间隔改成热生效：面板改 `checkSec` 不用重载模块。
- 新增 `/看直播 自检` 和 `/selfcheck` 接口。
