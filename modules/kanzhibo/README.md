# 看直播 · kanzhibo

给 [Aurabot（大肥鱼 QQ 插件）](https://github.com/accomplish07zrh-eng/dsh-aurabot-qq) 用的扩展模块。
让大肥鱼在抖音直播间「挂着」，顺便把该做的事做掉。

- 扩展接口：v1（`api: 1`）
- 插件版本要求：>= 1.2.0
- 运行平台：Windows / macOS（要装有 Edge 或 Chrome；Node 需要全局 `WebSocket`，即 22+）

## 它干什么

1. **进直播间**：开一台**独立**的浏览器（自己的 profile，不动你平时用的那个），通过 CDP 挂进直播间。
   给直播间地址最稳；给主播主页（`douyin.com/user/...`）会自己找「直播中」点进去。
   已经在同一个直播间里就**不刷新**（刷新会把播放和评论都打断）。
2. **和「刷抖音」互斥**：进房期间把 `douyin.enabled` 关掉；离开直播间 / 关掉挂直播之后自动放回来
   （先晾 10 分钟，免得两个浏览器抢同一个 profile）。暂停状态写在 `state.json` 里，插件重启也不会让刷抖音一直关着。
3. **进房评论**：等页面真的渲染出评论框（有可见的 `textarea` / `contenteditable`）再发一条你定的评论，一天一次。
   真的鼠标点框 → `Input.insertText` → 点「发送」或回车 → 回读框里还有没有字来验证。
4. **续粉丝团灯牌**：先看「今日任务」面板里灯牌那行是不是「已完成 / 已送出 / 已领取 / 已点亮」，
   没送才点左上角的粉丝团，弹出面板后再点「赠送 / 点亮 / 续费」。送完再判定一次，确认了才记「今天送过」。
   当天同一个直播间确认送出过就直接跳过（不重复点、不刷日志）。
5. **送礼物 / 替你说话**（只在主人明说时才做）：开礼物面板 → 按名字找礼物 → 点赠送 →
   用「抖币余额变少 / 出现赠送成功提示 / 飘屏里有礼物名」三个里任意一个确认真的送出去了；
   页面弹充值或抖币不足就立刻停。

## 用法

QQ 里（只有主人能发）：

```
/看直播            状态
/看直播 状态       同状态
/看直播 开         打开挂直播并立刻进一次房
/看直播 关         关掉挂直播，把刷抖音放回来（浏览器窗口先留着）
/看直播 进         立刻进一次房
/看直播 收工       关掉浏览器，刷抖音晾 10 分钟再放开
/看直播 自检       体检单：浏览器、CDP、时段、刷抖音、今日评论/灯牌
```

她自己在聊天里也能用（模型按需调用）：

| 工具 | 什么时候用 |
|---|---|
| `kanzhibo_enter` | 「去看直播」「去 XX 的直播间」「帮我挂着」 |
| `kanzhibo_status` | 「你在看什么直播」 |
| `kanzhibo_stop` | 「别看了」「关掉」「回来吧」 |
| `kanzhibo_gift` | 主人明确说了送什么礼物时才用（灯牌不算礼物） |
| `kanzhibo_say` | 「在直播间说一句 XX」——原话照发，一个字不改 |

进房 / 停止 / 送礼 / 说话这四个是**真动作**（开浏览器、改配置、花抖币、用你的号发言），
只有「这一轮有主人说话」时才会挂给她；群里别人开口时她手上只有一个状态查询，而且那个状态不显示在看谁。

## 设置项（`config.json` 的 `ext.kanzhibo`）

| key | 类型 | 默认 | 说明 |
|---|---|---|---|
| `enabled` | switch | `false` | 挂直播总开关 |
| `target` | text | `''` | 直播间地址或主播主页 |
| `checkSec` | number | `120` | 多久检查一次（30–1800 秒，改了立刻生效，不用重载） |
| `schedule` | switch | `false` | 只在指定时间段挂 |
| `startTime` / `endTime` | text | `20:00` / `23:30` | 24 小时制，支持跨午夜（`22:30`–`01:00`） |
| `liveCommentOn` | switch | `false` | 启用进房评论（默认关） |
| `liveComment` | textarea | `''` | 评论内容，多行只发第一行 |
| `commentDelaySec` | number | `8` | 进房后等几秒再发 |
| `renewBadge` | switch | `false` | 进房后送灯牌 |
| `badgeDelaySec` | number | `30` | 进房后等几秒才开始送（5–600） |
| `minuteReport` | switch | `false` | 进房时在 QQ 里说一声（调试用） |

## 自检

```bash
node test/verify.mjs            # 36 项逻辑检查：注册、主人权限、时段判定、每日去重、崩溃恢复
set LIVE=1 && node test/verify.mjs   # 再加 3 项：真起 Edge / CDP 连上 / 收工能关
```

脚本喂的是假 `api`：不发 QQ、不改真配置、数据落在临时目录。Windows 用 `set`，macOS/Linux 用 `LIVE=1 node ...`。

QQ 里 `/看直播 自检` 会给一份体检单；面板里也能调 `GET /aurabot/api/ext/kanzhibo/selfcheck`（JSON）。

## 会访问什么、会留下什么

| 访问目标 | 用途 |
|---|---|
| `https://live.douyin.com/…`、`https://www.douyin.com/user/…` | 进直播间、在主播主页找「直播中」、发评论、点灯牌 / 礼物 |
| `http://127.0.0.1:9300-9699/…` | 本机 CDP，只用来控制它自己启动的那台浏览器 |

除了上面这两类地址，不发任何其它网络请求；Cookie、聊天内容、账号信息都不会被发到别处。

在本机会做三件事：在 `modules-data/kanzhibo/live-profile/`（`api.dataDir()`）里放一个**独立**的浏览器 profile
（这里会有抖音登录态）、在 `state.json` 里记今天评论 / 灯牌做没做过、用 `api.setConfig` 改 `douyin.enabled` 这一个布尔值。

## 第一次用要手动登一次抖音

专用浏览器的 profile 在 `plugins-data/aurabot/modules-data/kanzhibo/live-profile/`，
是空账号。第一次让它进房后，在弹出的那个窗口里扫一下码登录——之后一直有效。
没登录也能看，但发评论、送灯牌、送礼都会失败（页面没有对应控件）。

## 它靠什么判断（改代码前先看这里）

| 判断 | 依据 |
|---|---|
| 在不在直播间 | `location.href` 以 `https://live.douyin.com/` 开头 |
| 页面加载完了 | 有可见的 `textarea` / `contenteditable`，或标题含「直播 / 直播间」 |
| 灯牌「今天送过了」 | 今日任务里「灯牌」+「已完成 / 已送出 / 已领取 / 已点亮」 |
| 评论发出去了 | 点完发送后回读输入框，还含有前 3 个字就算没成功 |
| 礼物送出去了 | 抖币余额变小 / 「赠送成功」提示 / 飘屏出现「礼物名 x N」 |
| 要充值了 | 页面出现「充值 / 抖币不足 / 余额不足 / 去充值」 |

找元素一律用「真实鼠标坐标点击」（`Input.dispatchMouseEvent`），因为直播间的面板多半按坐标判定，
`el.click()` 经常没反应。挑元素时优先**文字短、靠左上、面积最小**的那个——不加限制会点到顶部导航。

## 已知限制

- 抖音改版会换 DOM：找评论框、找「今日任务」、找粉丝团入口都可能失效，报错会写进面板「日志」页（按模块 id 分类）。
- 一台机器同一时间只挂一个直播间（一个 profile 一个窗口）。
- 送礼、发评论都是**用你自己的账号**在真实直播间里的真实动作，没有撤回。
- 不处理验证码：页面弹验证码时它只会失败并把原因说出来。

## 变更

### 0.3.1（2026-11-05）

- 修：群里谁都能让她去挂直播 —— 进房 / 停止 / 送礼 / 说话这四个工具原来在群聊里也挂着，
  而且只有送礼和说话看了主人身份。现在按 `turnHasOwner(sessionId)` 判断：没主人的那一轮只给状态查询，
  状态里也不显示目标主播和当前地址。
- 修：冷却定时器被无限推后 —— `tick()` 每轮都调 `resumeDouyin({ delayMs: 10 分钟 })`，
  每次调用都重排定时器并打一条「直播间刚关」，冷却永远到不了点（刷抖音一直关着），
  日志还被这条刷满（实测凌晨每 2 分钟一条）。现在冷却期内直接返回，不重排、不重复打日志。
- 修：`ensureInRoom()` 在 CDP 已经掉线时会拿 `null` 调 `cdp.close()` 抛 TypeError，改成判空。
- 改：规则按 `private` / `social` 分开写，群里明确「别人让你进房、送礼、代发弹幕都别做，也别主动说在看谁」。

### 0.3.0（2026-11-04）

- 修：崩溃恢复是死代码 —— `resumeDouyin()` 开头的「没暂停过就早退」守卫让加载时那条恢复分支永远走不到，
  刷抖音会一直关着。现在先把内存标记立起来再走正常恢复流程。
- 修：续灯牌点错位置 —— 找「粉丝团 / 灯牌」没限文字长度，包住整页文字的大容器也能匹配上，
  结果点到了顶部导航。现在只认短文字、靠左上、面积最小的元素；二次确认也只在那块面板里找。
- 修：灯牌成功后每 2 分钟重复打一条「今天已经送出了」刷满日志 → 当天同一直播间直接跳过。
- 改：检查间隔热生效（面板改 `checkSec` 不用重载模块）。
- 加：`/看直播 自检`、`GET /api/ext/kanzhibo/selfcheck`、`selfCheck()` 导出。

### 0.2.0

- 加灯牌、送礼、替主人说话；评论按天去重；和刷抖音互斥。
