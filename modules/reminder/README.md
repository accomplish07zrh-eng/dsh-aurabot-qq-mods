# 约定提醒

她说「明天提醒你交作业」的时候，真的会到点来说；主人也可以直接发 `/提醒 明天早上八点 交作业`。

## 做什么

- 给她一个工具 `remind_set(text, when)`：聊天里答应要提醒的事，记下来
- 主人可以在 QQ 里直接发命令：`/提醒 明天早上八点 交作业`
- 到点主动在那个聊天里说一句（没指定聊天就发主人私聊）
- 时间写法认得：`明天早上八点`、`明早`、`20:30`、`两小时后`、`10分钟后`、`晚上八点`、`半小时后`

记不下、听不懂的时间会当场说出来，不会悄悄丢掉。

## 怎么用

装上就生效，设置里可以关掉「能记约定」。

```
你：明天早上八点提醒我交作业
她：记下了，明天八点说。
（第二天 08:00）
她：想起来要跟你说：交作业
```

也可以直接命令：`/提醒 两小时后 收衣服`

## 会访问什么

不联网、不读写账号配置。只往插件发消息（`api.send`），数据存在模块自己的目录里。
