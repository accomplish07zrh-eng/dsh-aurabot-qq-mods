# 待办调度

Aurabot 的独立 Todo 模块，不依赖 Brain。它可以记录需要跨当前对话继续处理的事情，在指定时间把念头递给目标聊天；也支持立即执行、重复提醒，以及可选的早安和晚安问候。

## 安装

把模块放进 Aurabot 的 `modules/todo/` 目录，在“已安装模块”中开启。它需要运行在 Aurabot 内，不能脱离 Aurabot 单独启动。

## 自主待办（1.1.0）

面板新增默认关闭的“自主待办”开关。打开后，AI 可以在任何对话场景中自行决定是否记录后续事项、何时再联系，不需要用户明确指定时间。不是后台无限思考器：只有模型回合中实际调用工具才会创建任务。尊重勿扰、休息和权限，不允许用立即任务循环轰炸用户。

`todo_add` 可额外传 `date: "YYYY-MM-DD"` 或 `delayMinutes`（向上取整到分钟）；例如“明天找你”应指定明天日期，“一会回来”可指定延迟。默认安排一次，之后根据互动决定是否继续。

## 安全修改与撤回

先用 `todo_list` 获取唯一 ID；通过 `todo_update`、`todo_cancel` 或 `todo_done` 请求修改、撤回或完成。AI 必须展示任务详情及修改差异，用户在同一聊天用工具提供的“确认 操作 ID 口令”明确确认后才执行。确认绑定原用户，10分钟有效且只能使用一次；任务变化、触发或重载后需要重新确认。等待确认期间原计时器继续运行，不会因为请求撤回自动暂停。

面板撤回属于用户直接操作；聊天里的 AI 不能绕过上述确认流程。

## 什么时候使用

这些情况应记录到 Todo：

- 需要下一轮、稍后或明天继续处理的承诺。
- 需要去另一个私聊找人、询问或提醒的跨聊天任务。
- 需要在明确时间再次提醒的事情。
- 没有具体时间，但必须马上开始处理的后续任务。

任务进入 Todo 只表示已经安排，不表示事情已经完成，也不表示已经收到对方回复。

## 格式

模型使用 `todo_add`，每条待办一行：

```text
来源对话|念头和原因|目的对话|时间|次数|重复间隔分钟
```

字段说明：

- 来源对话：例如 `private:123` 或 `group:456`。
- 念头和原因：写清楚要跟进什么，以及为什么要跟进。
- 目的对话：要递送念头的聊天。
- 时间：`HH:MM`，例如 `14:30`；没有明确时间就填 `0`，表示立即安排。
- 次数：`1` 表示一次，`3` 表示三次，`-1` 表示每天重复。
- 重复间隔分钟：可选；多次提醒时填写，例如 `5` 表示每隔 5 分钟。

## 示例

定时提醒三次，每隔五分钟：

```text
private:123|提醒他提交作业，因为截止时间快到了|private:456|14:30|3|5
```

立即安排一次跨聊天任务：

```text
private:123|去问他是否收到文件，回来后告诉我结果|private:456|0|1
```

每天固定时间主动提醒：

```text
private:123|每天提醒他早点休息，因为他最近总是熬夜|private:456|23:00|-1
```

## 早安和晚安

在面板中分别开启“早安问候”和“晚安问候”。两者可以分别设置候选名单和人数范围：

- 早安：每天 0 点生成，通常在 8:00–10:00 触发。
- 晚安：每天 0 点生成，通常在 20:00–22:00 触发。
- 候选名单可每行填写一个 QQ 号；留空时使用最近两天聊过的私聊。
- 候选对象必须在 Aurabot 的私聊白名单中。
- 问候会请求模型尽量使用语音，但不保证最终一定发送语音。

## 已知问题

- 电脑和 DSH 未运行时不会触发；重新启动后会恢复未完成任务。
- 关机期间错过的普通任务只会尝试补触发一次，不会逐次补发。
- 如果任务递送失败，目前没有可靠的自动重试。
- 每天 0 点离线时，当天早晚问候计划不会自动补生成。
- 跨聊天任务只负责递送念头，不保证一定拿到结果或把结果带回来源聊天。
- 早晚问候属于主动联系，请确认收件人接受此类消息。

待办数据保存在 Aurabot 的本地模块数据目录，不会上传到本项目仓库。
